What is Adwait?

Adwait is a free, local-first pomodoro timer and task list in one pane. Today's tasks sit on the left, colour-coded by whether they're overdue, due today, or upcoming. The timer sits on the right, and every focus session is logged against the day — and against a task, if you want. There is no account and no server: tasks, buckets, and sessions are stored in your browser, and you can export a JSON backup at any time.

The name comes from Sanskrit advaita (अद्वैत), "not two" — the work and the time spent on it are one.

Common questions

Is Adwait really free?

Yes. The app is free to use, has no ads, and requires no account. There is nothing to upgrade to and no trial that expires.

Where is my data stored?

In this browser's localStorage, under the key adwait:v1. Nothing is sent to a server. Export a JSON backup from the header now and then, and import it on another machine or browser when you need to move.

Does the timer keep running if I close the tab?

The timer stores an end timestamp rather than counting down, so it stays accurate through refreshes, background tabs, and sleep. If a session finishes while the tab is closed, it is recorded once when you come back.

Can I use it on my phone?

It works in a mobile browser, but the layout is designed for a desktop screen. There is no native app and no sync between devices — use export and import to move data.
