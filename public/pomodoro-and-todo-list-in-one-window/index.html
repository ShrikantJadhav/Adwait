One pane

Your todo list and pomodoro timer, in one window

The usual setup is a task app, a timer in another tab, and a vague sense afterwards of where the afternoon went. Adwait collapses that into one screen and makes the link explicit: every focus session belongs to a task.

What three tabs actually cost

A timer in a background tab is a tab you can't see. You start a session, go back to work, and either forget it ended or lose track of which task it belonged to. Then the honest accounting is gone: at the end of the week you know you were busy, not what consumed the time.

Putting the timer next to the list fixes two small things that compound: you pick the task before the session instead of writing it down after, and the timer stays visible while you work because it's part of the same view.

How the single pane is laid out

  • Left: today. Overdue, due today, pinned, Later, and done-today groups, with bucket chips showing where each task lives and colour-coded due dates (red overdue, amber today, green upcoming).
  • Right: the timer. Focus, short break, long break; the task you're working on; start, pause, resume, cancel.
  • Buckets. Projects (Work, Personal, Finance…) each get a view with their own tasks and total focus time. Drag to reorder inside a bucket, or drop a task onto another bucket tab to move it.

What gets logged

Each finished session records a start time, an end time, and a duration, and is linked to the task it was started against. Time-taken on a task is the sum of its completed sessions — not an estimate, not a guess. Sessions started without a task can be attached to one afterwards, so a stray 20-minute block isn't lost. Cancelled sessions are logged as cancelled and kept out of the main total.

When Adwait is the wrong tool

If you need a team to see the list, reminders on your phone, or calendar integration, this isn't it. There's no sharing, no sync, no notifications outside the browser, and no mobile app. Adwait is deliberately a single-person, single-machine tool. The value is the focus, not the coverage.
